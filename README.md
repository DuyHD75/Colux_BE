📝 Create microservices config rules

2. Spring boot version: 3.2.6
3. Group: 'com.dcode.microservices' => use this sample for all microservices
4. Artifact: <name-of-microservices>
5. Description: <Describe what service do ex: 'Implement Api-Gateway For Colux Application '>
6. Dependencies required: DevTool, Spring Web, Actuator

⬇️ Clone Git Rules
1. Clone project by URL
2. Check out develop branch
3. Fetch in develop branch
4. Implement your service

*. BEFORE CREATE NEW BRANCH COMMIT CODE IN THE CURRENT BRANCH 
1. Prefix FEATURE branch name : 'feature/<SERVICE_NAME>/<NAME_OF_FEATURE>'
2. Before merge code into the develop -> create new PULL REQUEST => REVIEW CODE
